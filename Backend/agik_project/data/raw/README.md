# data/raw

Сюда кладутся **сырые xlsx-отчёты** учреждений. Эта папка **не коммитится** (см. `.gitignore`).

## Формат файла

Каждый xlsx — один отчёт одной организации. Ожидаемые листы:
- `ТИТУЛ`
- `ФОРМА 1`
- `Приложение к отчету Ф1`
- `ФОРМА 2`

## Как использовать

1. Скопируй свои xlsx-файлы сюда ("АГИК"     
    "театриум"
    "ВГИИ"
    "Андрияки"
    "гмп")
2. Запусти:
'''
py parse_reports.py # соберёт data/clean/
py aggregates.py # среднее, z-score, кластеры
py validate.py # проверит целостность
'''

3. Результаты появятся в `data/clean/`

## Важно

Папка **игнорируется git** — данные у каждого свои.
В репозитории хранится только результат (`data/clean/`) и код.
