## ➕ Как добавить новое учреждение

1. Положи xlsx в `data/raw/` — он должен иметь **те же 4 листа**:
   `ТИТУЛ`, `ФОРМА 1`, `Приложение к отчету Ф1`, `ФОРМА 2`.

2. Открой `parse_reports.py` и **допиши строку** в словарь `FILE_TO_ID`:

   ```python
   FILE_TO_ID = {
       "АГИК":     "agik",
       "театриум": "teatrium",
       "ВГИИ":     "vgii",
       "Андрияки": "andriyaki",
       "гмп":      "gmp",       # ← новое
   }
   ```

   Ключ — имя файла **без `.xlsx`**, значение — `institution_id` (латиницей).

3. Перезапусти:
   ```
   py parse_reports.py && py aggregates.py && py validate.py
   ```

4. Проверь `data/clean/validation_report.json` — там будут warnings по расхождениям сумм.

## 📊 Схема `indicators`

| Поле | Тип | Что значит |
|---|---|---|
| `institution_id` | str | `agik` / `teatrium` / `vgii` / `andriyaki`  / `gmp` |
| `form` | str | `form1` / `appendix_f1` / `form2` |
| `code` | str | номер показателя: `1`, `2`, `3.1`, `4.2`, `6.3` |
| `parent_code` | str \| null | родитель для подпунктов (`3` для `3.1`) |
| `level` | int | 0 — родитель, 1 — подпункт |
| `name` | str | название показателя |
| `unit` | str | `единиц` / `человек` / `рублей` / `процент` |
| `plan_2025` | float \| null | значение 2025 |
| `fact_2026` | float \| null | значение 2026 |
| `plan_percent` | float \| null | плановый %, только для form1 |
| `deviation` | float \| null | факт − план |
| `deviation_pct` | float \| null | отклонение в % |
| `formula` | str \| null | формула расчёта |
| `evidence` | str \| null | URL / ссылка на подтверждающий документ |

## 📊 Схема `aggregates` (доп. колонки к `indicators`)

| Поле | Что значит |
|---|---|
| `group_mean` | среднее по всем 4 учреждениям |
| `group_std` | стандартное отклонение |
| `group_min` / `group_max` | мин/макс по группе |
| `group_count` | сколько учреждений дали число |
| `z_score` | (факт − среднее) / std, для кластеризации и рекомендаций |
| `deviation_from_mean_pct` | отклонение от среднего в % |

## 📊 Схема `clusters`

| Поле | Что значит |
|---|---|
| `institution_id` | ID |
| `residents` | значение по Ф2 коду 3 |
| `products` | значение по Ф2 коду 4 |
| `services_rub` | значение по Ф2 коду 6 |
| `cluster` | 0 / 1 — номер кластера (k-means, k=2) |
| `cluster_label` | `cluster_A` / `cluster_B` |

## 🎯 Что можно построить на этих данных

| Блок ТЗ | Что можем | Роут для бэкенда |
|---|---|---|
| Несколько учреждений | 4 организации, сравнение | `GET /institutions` |
| KPI-карточки | ключевые показатели по каждому | `GET /overview?institution_id=X` |
| Динамика | план 2025 vs факт 2026 | `GET /dynamics` |
| Сравнение | показатели бок о бок | `GET /compare?ids=agik,vgii` |
| Кластеризация | cluster_A / cluster_B | `GET /clusters` |
| Рекомендации | где z < −1 → «подтянуть» | `GET /recommendations` |
| Топ учреждений | сортировка по факту | `GET /top?metric=services_rub` |

### ❌ Чего в данных НЕТ

- ежедневной/ежемесячной посещаемости
- обратной связи (оценок, отзывов)
- типов мероприятий (спектакль / концерт / выставка)
- демографии аудитории

**Для ТЗ «обратная связь и вовлечённость»** используем **косвенные** метрики: резиденты, созданные продукты, участие в мероприятиях, публикации.

## 🧠 Что умеет парсер

- Читает все 4 листа (**ТИТУЛ, Ф1, Прил. Ф1, Ф2**) из каждого xlsx
- Вытаскивает метаданные: организация, центр, даты, подписантов
- Приводит числа: `"1 224 900"` → `1224900.0`, `"не требуется"` → `None`
- **Разворачивает простые Excel-формулы** в колонке факта:
  - `=C13+C14+C15+C16+C17` → сумма значений этих строк
  - `='Приложение к отчету Ф1'!D4+...` → формула **не разворачивается**, → `None`
- Разделяет название и единицу измерения: `"…, единиц"` → `("…", "единиц")`
- Ловит подпункты Ф2 (`3.1`, `4.2`) — код внутри текста, не в колонке A
- Считает `deviation` и `deviation_pct` от плана
